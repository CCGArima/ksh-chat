# 📋 ИСТОРИЯ ИЗМЕНЕНИЙ И ДОРАБОТОК KSH CHAT

---

### 🚀 1. Запуск в 1 клик для ВСЕХ операционных систем (Windows, Mac, Linux)
- **Windows (`run_ksh.bat`):** Двойной клик запускает чат на Windows.
- **macOS (`run_ksh.command`):** Двойной клик в Finder сразу открывает Терминал и запускает чат.
- **Linux (`run_ksh.sh`):** Двойной клик (или `./run_ksh.sh`) запускает чат на Linux.

---

### 🔀 2. Исправление ошибки `Decryption Error` (Mac ↔ Windows)
- **Что было:** На Mac использовался модуль `cryptography` (AES-GCM), которого по умолчанию не было на Windows. При отправке сообщений возникала ошибка `Decryption Error`.
- **Что изменилось (`crypto.py`):** Весь чат переведен на единый асинхронный шифратор `HMAC-SHA256 Stream Cipher` на чистом Python. Теперь сообщения между Mac и Windows расшифровываются со 100% совместимостью без установки любых pip-пакетов.

---

### ⚡ 3. Автоматическое создание комнаты и входа
- **Что изменилось (`ksh.py`):** При выборе пункта **`1` (Создать закрытую комнату)** программа сама в фоне запускает сервер и сразу вводит вас в чат под вашим никнеймом.

---

### 🔑 4. Код подключения в 1 клик (`KSH-XXXX`)
- **Что изменилось (`ui.py`, `client.py`):** Программа генерирует единую строку **`KSH-MTky...`**. Друг выбирает пункт **`2`**, вставляет эту строку, и клиент сам расшифровывает IP, порт и пароль для моментального подключения.

---

### 🎲 5. Выбор: Случайный или Постоянный код
- При создании комнаты вы можете:
  - Нажать `Enter` — сгенерируется новый случайный код.
  - Ввести свой пароль (например, `1234`) — код подключения будет **постоянным всегда**.
