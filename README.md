## ✨ Ключевые возможности

1. **🌐 Облачный KSH Сервер 24/7 (Вход в 1 клик):**
   * Выбираете пункт `[1]` — и вы сразу в общем чате с друзьями.
   * Никаких открытий портов, роутеров, IP-адресов и временных кодов.
   * Сервер развёрнут в облаке Render на базе постоянного WebSocket-протокола (`wss://`).

2. **🔐 Надежное сквозное шифрование (Zero-Knowledge E2EE):**
   * Шифрование сообщений происходит прямо на устройстве пользователя.
   * Алгоритм: деривация ключей `PBKDF2 HMAC-SHA256` (100 000 итераций) + аутентифицированный потоковый шифр с проверкой целостности `HMAC-SHA256`.
   * Сервер передаёт только зашифрованные пакеты и не имеет доступа к содержимому переписки.

3. **🏠 Режимы локальной сети и P2P-туннелей:**
   * **LAN / Wi-Fi (UDP Beacon):** авто-поиск серверов в домашней сети за 1 секунду без ввода IP.
   * **WAN SSH-туннели:** возможность поднять собственный временный сервер через Pinggy/SSH.
   * **Присоединение по коду:** генерация защищённых токенов вида `KSH-XXXXX`.

4. **💻 Кроссплатформенность и защита консоли:**
   * Запуск на Windows, macOS и Linux.
   * Готовые лаунчеры в 1 клик (`start_windows.bat`, `start_mac.command`).
   * Автоматическая проверка и фоновая установка недостающих библиотек (`websockets`).
   * Встроенный обход зависания консоли Windows (отключение блокирующего режима `QuickEdit`).

## 🚀 Быстрый запуск

### Вариант 1. Запуск через готовые файлы (для пользователей)

* **Windows:** Дважды кликните по файлу **`start_windows.bat`** (или `run_ksh.bat`).
* **macOS / Linux:** Дважды кликните по файлу **`start_mac.command`** (или запустите `run_ksh.sh`).

*(Скрипт сам проверит окружение и при необходимости доставит нужные модули).*

---

### Вариант 2. Запуск через терминал (для разработчиков)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/CCGArima/ksh-chat.git
   cd ksh-chat
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите клиент:
   ```bash
   python3 ksh.py
   ```

## 💬 Команды внутри чата

| Команда | Описание |
| :--- | :--- |
| `Обычный текст` | Публичное сообщение всем участникам текущей комнаты |
| `/users` | Показать список активных пользователей в комнате |
| `/pm <ник> <текст>` | Отправить приватное зашифрованное сообщение |
| `/nick <новое_имя>` | Сменить свой никнейм на лету |
| `/clear` | Очистить экран терминала и перерисовать шапку |
| `/help` | Вывести интерактивную справку |
| `/quit` или `/exit` | Выйти из чата обратно в меню |

## 🛡️ Безопасность и архитектура шифрования

1. **Деривация ключей:**  
   Ключ шифрования генерируется на клиенте из пароля комнаты через `hashlib.pbkdf2_hmac` со 100 000 раундов SHA-256 и солью приложения.
2. **Аутентифицированный шифр:**  
   Каждое сообщение шифруется потоковым шифром с уникальным случайным 16-байтным `nonce`. Целостность пакета защищена криптографической подписью `HMAC-SHA256`. Любая попытка подмены или расшифровки с неверным паролем немедленно отбрасывается клиентом.
3. **Чистый Python:**  
   Криптографическое ядро работает исключительно на базе стандартной библиотеки Python 3 (`hashlib`, `hmac`, `os`, `base64`), что исключает проблемы с компиляцией OpenSSL и гарантирует 100% совместимость на любых ОС.
