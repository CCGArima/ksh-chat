# 🔴 KSH PRIVATE CONSOLE CHAT

Закрытый асинхронный консольный чат с зашифрованными комнатами, красным стилизованным интерфейсом в стиле Cyberpunk/Terminal и логотипом **KSH**.

Работает на **Linux**, **macOS** и **Windows** (поддержка CMD, PowerShell и Windows Terminal).

## ⚡ Максимально простой запуск (По Коду Подключения)

Вам больше не нужно вводить IP-адреса и настраивать порты вручную!

### 👑 Если вы Создатель (Host):
1. Запустите чат:
   ```bash
   python3 ksh.py
   ```
2. Выберите пункт **`[1] Создать закрытую комнату`** и введите ваш Никнейм.
3. Сервер запустится автоматически, вы сразу попадете в чат, а вверху экрана появится **🔑 КОД ДЛЯ ДРУЗЕЙ**:
   `KSH-MTkyLjE2OC4xLjE1Ojk5OTk6ODQ5MjAxOmdsb2JhbA`

### 👥 Если вы Участник (Guest):
1. Запустите чат:
   ```bash
   python3 ksh.py
   ```
2. Выберите пункт **`[2] Присоединиться по коду`**.
3. Введите свой никнейм и скопируйте **КОД ДЛЯ ДРУЗЕЙ**.
4. Вы мгновенно подключитесь к чату!

## 🛠️ Команды в чате

| Команда | Описание |
| :--- | :--- |
| `/help` | Вывести справку по командам |
| `/users` | Показать список участников в текущей комнате |
| `/pm <nick> <msg>` | Отправить приватное зашифрованное сообщение пользователю |
| `/nick <new_nick>` | Сменить текущий никнейм |
| `/clear` | Очистить консоль и перерисовать шапку KSH |
| `/quit` | Выйти из чата |

---

## 🔐 Безопасность и Шифрование

1. При создании комнаты автоматически генерируется временный ключ доступа.
2. Сообщения шифруются на стороне клиента (`PBKDF2 HMAC SHA-256` + `AES-256-GCM` / `HMAC-XOR`).
3. Сервер работает в режиме Zero-Knowledge и пересылает только зашифрованные пакеты.
